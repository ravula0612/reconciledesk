File requirements and calculation

Use UTF-8 CSVs for one period and one currency. Each file can have up to 100,000 rows and be up to 10 MB. Use one row per invoice, a unique ID per cost, and nonnegative decimal amounts. Include a zero-cost row if an invoice has no cost. Files are processed in your browser.

The same rate applies to each invoice. Commission is rounded to cents per invoice and calculated on positive gross profit. Missing or duplicate linked costs and duplicate invoice IDs put the calculation on hold.
